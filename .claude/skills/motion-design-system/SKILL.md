# Motion Grammar

Motion is part of communication.

Never animate something simply because animation is available.

## Hierarchy

1. Narrative transition
2. Information reveal
3. Relationship / connection
4. Emphasis
5. Resolution

## Intensity

Default:

- opacity: subtle
- translation: 8–40px
- scale: 0.92–1.0 for entrances
- emphasis scale: maximum 1.04
- no repeated zoom loops

## Text

Text should enter once, settle, remain stable, and emphasize only important words.

Do not continuously animate paragraphs.

## Data

Metrics may count upward, highlight, then settle.

## Systems

System diagrams may reveal nodes, draw connections, move data packets, and highlight active paths.

## UI

Interfaces may build progressively, reveal cards, highlight actions, and move through states.

Do not animate the whole UI container unnecessarily.

## Transitions

Prefer:

- crossfade
- directional flow
- shared-element continuity
- transform

Avoid:

- hard black cuts
- arbitrary zoom transitions
- unrelated scene movement
